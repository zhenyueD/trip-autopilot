## 保留的可靠性修复

| 问题 | 本版行为 | 证据边界 |
| --- | --- | --- |
| Writer 工具历史与低推理配置不兼容 | 按合法工具历史保留可用配置，保留协议配对与输入计量 | 离线 native payload/tokenizer 复验；不宣称解决所有延迟 |
| 重复目录和不必要首读 | 上下文使用当前目录投影；完整可写字段直接编辑，缺项或冲突定向读取 | 原历史留审计；更长会话仍可能触输入上限 |
| 已干净草稿误计无进展 | 对检查、修补、发布的实际进展计账，保留有界停止 | 当前生成仍可能耗时较长，未保证新单首次成功 |
| 超时后晚写、取消后证据污染 | 同一作用域/作业身份约束写入，先保存终态再清理 | 同进程锁；不声称强杀外部请求、跨进程事务或撤回费用 |
| 调度或持久化失败假装运行 | 四入口和 Future 异常映射到实际作业；存盘失败明确 not_persisted | 存储彻底不可写时不能凭空保证持久化 |
| 同版产物状态没有刷新 | 保持阅读 iframe，单独刷新状态/版本/下载能力 | 第一眼仅 ready 展示普通下载 |
| 媒体重复获取 | 已选照片和相同路线地图复用，缺图仍明确为缺口 | 不用地图或错误实体图片顶替景点照片 |
| 预览请求头兼容与诊断 | 合法 Cookie 兼容、分帧拒绝、脱敏诊断 ID | 本地回归通过；公网旧进程未替换、未宣称公网根因全闭合 |

## 发布整合中的两处适配

冻结开发副本的 `tools/render_service.py` 和 `packages/travel_agent/supply_render_queue.py` 使用本机研究目录；直接覆盖公开版会使 `start_customer_preview.py` 的独立渲染目录健康检查失败。

本版保留上一公开版本已有的环境变量/用户本地目录适配：队列读取 `TRAVEL_RENDER_BRIDGE`，渲染输出读取 `TRAVEL_RENDER_OUTPUT`。差异只涉及 `os` 导入、默认目录和环境变量；渲染逻辑、模型、prompt 与产品判定没有修改。逐文件前后 hash 在源码清单的 `release_overlays` 中。

## 最近一次真实模型结果（本次发布之前）

同一个扬州缓存 v2 的隔离副本，通过真实前端提交一次要求：第二天不去大明寺，瘦西湖后回酒店休息，晚饭在酒店附近，其他两天与日期/人数/预算上限不变。

| 项目 | 实测 |
| --- | --- |
| 修改 | v3 实际保存，日程、摘要和第一眼路线同步；第一天/第三天完整结构保持 |
| 回执 | diff、改了什么、判断、替代方案、下一步在册 |
| 阅读/刷新/导出 | 同一版本 HTML、18 页完整 PDF、3 页第一眼 PDF，前端下载与存档字节 hash 相同；刷新未增加调用 |
| 时间 | 提交至终态观测 494.628 秒（8 分 15 秒） |
| 调用 | 4 次：2 次编辑模型、2 次媒体模型；第一次旧值不匹配被原子拒绝，第二次修正后保存 |
| Tokens | input 44,886 / output 46,207；其中 reasoning 34,074 已包含在 output 内；未知 token 用量 0 |
