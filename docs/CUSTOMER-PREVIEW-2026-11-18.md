# 临时 HTTPS 验收说明

本说明对应 2026-11-18 候选交付版本。历史版本已有生成、修订、手册、双 PDF 与同浏览器恢复的通过记录；**本轮隔离 HTTPS 部署和真实 Chromium 登录已完成，新数据目录的生成与修订验收正在进行**。2026-11-18 临时入口由运行者私下提供，口令不公开。以下命令与实际启动脚本对齐。

## 1. 准备运行环境

使用干净克隆，按仓库根目录 [README](../README.md) 解密新包、安装依赖与 Chromium、配置并导出环境变量。

- 本轮命令面向 macOS、Python 3.13；Windows/Linux 尚未在本轮实测。
- `cloudflared` 必须可从 `PATH` 调用。
- 必需环境变量是 `DEEPSEEK_API_KEY`。可选服务配置见 `.env.example`；脚本不会自动读取 `.env`。
- 使用新包 `core/packages-session-20261118.tar.gz.enc`，交互式执行 `openssl enc -d -aes-256-cbc -pbkdf2`，再解包得到 `packages/`。解密口令单独保管，不写入仓库、命令参数或发布日志。
- 旧包 `core/packages-core.tar.gz.enc` 保留，不用于覆盖本次解出的 `packages/`。

加密包交付后端源码。解密操作不启动应用，也不连接旧私有库。本次应用的会话位置由下述仓库外目录显式指定。

## 2. 一条命令启动

激活 `.venv` 并导出环境变量后，在仓库根目录执行：

```sh
python tools/start_customer_preview.py \
  --state-dir ../trip-autopilot-preview-20261118 \
  --app-port 7393 \
  --gateway-port 7394 \
  --render-port 7395
```

`--state-dir` 是实际参数名，必须在源码仓库外。首次验收请使用新建的空目录，不指向历史运行目录。三个端口须互不重复且空闲；脚本不会接管已有服务。

| 本地端口 | 作用 | 对外访问方式 |
| --- | --- | --- |
| `7393` | 会话 API 与产品静态页面 | 通过认证网关转发 |
| `7394` | 口令登录与认证网关 | Cloudflare 临时 HTTPS 隧道的目标 |
| `7395` | Chromium 来源读取与渲染服务 | 仅本机内部使用 |

启动器创建独立的 `sessions/`、`render-bridge/` 和 `render-captures/`，并将运行状态写入同一仓库外目录。应用与网关均绑定 loopback。启动器先取得临时域名，再让网关仅接受该域名及本地访问 Host。

脚本显示 `Preview: https://…trycloudflare.com/studio.html` 后，打开该完整地址。入口是 **`/studio.html`**。验收口令位于状态目录的 `access.json` 中；运行者应私下向授权验收者提供口令，不提交该文件。`runtime.json` 与日志也留在该私有目录中。

口令由启动器生成并通过 `TRIP_PREVIEW_PASSWORD` 环境变量交给网关，不占用产品 API 的 Bearer Authorization。登录 Cookie 默认有效 8 小时，网关重启后失效，需要重新登录。

## 3. 在同一行程上完成验收

验收时保留同一浏览器、同一 HTTPS 域名与同一行程；记录行程标识、版本和文件，不合并不同新建行程的结果作为一次通过。

| 步骤 | 需要看到的结果 | 本轮状态 |
| --- | --- | --- |
| 登录保护 | 未登录的应用、静态资源、API 和下载路径被拦截；正确口令进入产品 | 已通过真实 HTTPS/Chromium 登录及认证边界检查 |
| 首次生成 | 从空数据目录提交一个新行程，最终保存可读手册，并记录总耗时 | 待实测 |
| HTML 展示 | 产品中的 iframe 显示当前行程、当前版本保存的 HTML，内容完整 | 待实测 |
| 同会话修订 | 在该行程输入修改要求，保存新版本，检查要求是否落实及修订耗时 | 待实测 |
| 双 PDF | 下载速览版与完整版，逐页检查内容、图片与当前版本对应 | 待实测 |
| 同浏览器恢复 | 保留浏览器本地凭证，刷新或重开同域名入口，恢复同一行程和版本 | 待实测 |

历史首次生成约为 **10–12 分钟**，不作为本轮时限承诺。小修订耗时要单独记录。进度在变化、后台进程存活或文件下载完成，都不足以证明手册内容与修改已验收。

遇到缺失事实或未确认条件，应在手册中保留不确定性。不能仅凭引用链接存在就认为事实正确；检查实际实体、日期和适用条件。

## 4. 已知边界与恢复

- Undo 端点尚未完成；本轮不宣称支持撤销闭环。
- 同浏览器恢复依赖同一访问来源及仍然存在的写凭证。跨浏览器、清除本地凭证或凭证丢失后的写权限恢复尚未完成。
- 临时隧道重启可能更换域名。即使沿用原状态目录，新的域名仍是新的浏览器来源；不能据此承诺恢复旧行程的写权限。
- Mac、网络和启动进程必须保持在线。这个临时入口没有持续可用性承诺。
- 本轮 Windows/Linux 兼容性及本轮新环境的完整生成、修订、PDF、恢复结果仍须实测确认。

停止时在启动终端按 `Ctrl+C`，启动器会关闭本次启动的应用、网关、渲染服务和隧道。状态目录保留；不要为了重试删除会话数据。再次执行同一命令会使用同一状态目录。

## 5. 常见故障

| 现象 | 检查 |
| --- | --- |
| 提示缺少 `DEEPSEEK_API_KEY` | 确认密钥已导出到启动进程环境；仅编辑 `.env` 不够 |
| 端口无法绑定 | 确认 `7393/7394/7395` 空闲；需要更换时同时传入三个互不冲突的端口 |
| 找不到 `cloudflared` | 检查安装及启动终端的 `PATH` |
| 来源渲染或 PDF 失败 | 确认当前虚拟环境已安装 Playwright Chromium，再查看状态目录的 `render.log` 与 `app.log` |
| 登录后出现 502 | 检查启动进程与 `app.log`、`gateway.log`；不要反复提交同一生成或修改要求 |
| 连续登录失败后出现 429 | 等待限流窗口后再试；网关全局限制 60 秒内最多 8 次登录尝试 |
| 重新登录后看不到原行程 | 先确认浏览器、域名与本地凭证是否改变；口令登录不等于恢复行程写凭证 |

日志、`access.json`、`runtime.json`、环境文件与会话目录可能包含凭证或私人行程，只在运行者控制的仓库外目录保留。
